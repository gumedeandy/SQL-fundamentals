# SELECT Queries

## Overview
The `SELECT` statement is used to retrieve data from one or more tables. It allows you to filter, sort, and display specific columns.

## Learning Objectives
- Retrieve all data from a table
- Select specific columns
- Filter results using `WHERE`
- Sort results using `ORDER BY`
- Use `LIMIT` to control output

## SQL Syntax

### show me or display All Columns
```sql
SELECT * FROM customers;

##Selecting Specific Columns##
SELECT full_name, email FROM customers;

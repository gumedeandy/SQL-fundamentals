# Database Creation

## Overview

A database is an organized collection of data that allows information to be stored, managed, and retrieved efficiently.

Creating a database is the first step before creating tables, inserting data, or writing SQL queries.

## Learning Objectives

- Understand what a database is
- Create a new database
- Connect to the database
- Prepare it for storing data

## SQL Syntax

```sql
CREATE DATABASE company_db;
```

## Example

```sql
CREATE DATABASE school_db;
```

This creates a new database called `school_db`.

## Real-World Example

Imagine opening a new restaurant.

Before you can record customers, orders, or payments, you first need a place to keep all that information.

A database is like the restaurant's filing cabinet. Everything is stored inside it.
